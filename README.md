### 🎯 Contribution Principles

- 🔬 **Reproduce First:** Always verify bugs and edge cases with dedicated unit/integration tests before writing patches.
- 🧹 **Clean & Maintainable:** Zero unnecessary dependencies, strictly typed signatures, and adherence to project style guides.
- ⚡ **Rapid Turnaround:** Focused, modular PRs that are easy for maintainers to review and merge.
- 🛡️ **Zero Regressions:** Every PR comes with automated regression tests to prevent recurrence.
